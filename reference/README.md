# Original reference

Open `index.html` directly in a browser to review the original layout 1a handoff.
Its sibling CSS and modal script remain independent of the application toolchain.
The demo signup succeeds after 700 ms without sending a network request.

The runnable application lives at the project root and in `src/`. This folder is
retained for comparison; application fixes go in `src/`, rather than changing this
reference. See `../DEVELOPMENT.md` for run commands and integration details.
