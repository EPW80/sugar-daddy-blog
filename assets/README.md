# Artwork

`sd-hero.svg` is the hero and signup illustration. `sd-c1.svg` through `sd-c5.svg`
illustrate the five featured sections in catalog order. These are the supplied
placeholders; photography direction is in the root README §11–12.

The application references these source assets directly from HTML; Vite packages them
into `dist/` automatically. Keep explicit dimensions and empty alt text for decorative
artwork, and preserve the inset gold frame when replacing images.
